# Supabase Login & Email Fix

A free, static checker for "my Supabase signup and password-reset emails aren't arriving". It checks a sender domain's SPF, DKIM, DMARC and MX records in your browser using public DNS-over-HTTPS. No backend, trackers or cookies, and it never asks for keys.

- `index.html`: the checker
- `offer.html`: the $49 screen-share fix
- `config.js`: the payment link, booking link and contact email (edit this file only)
